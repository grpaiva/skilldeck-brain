This is Skill Deck's second brain. It exists so that any teammate, contractor, or AI agent can get an accurate picture of the company and the product in a few minutes, without asking a founder.

Everything here is Markdown in a Git repository. Humans can edit it in the Mintlify dashboard, engineers can edit it in an IDE, and agents can read and edit it over MCP or the GitHub API.

## Skill Deck in one paragraph

Skill Deck is a frictionless Skill assessment and development platform for company teams. It analyzes 58 Skills from real work evidence and builds an individual behavioral profile based on facts, not on biased perception. From that profile, each person develops one Skill at a time through a Track. Employees just have to integrate the tool and work, while managers get real inputs from their workforce so they can put development on the agenda.

## What belongs here

| Belongs here | Does not belong here |
| --- | --- |
| Positioning, messaging, and approved claims | Engineering implementation detail and architecture decisions |
| How product concepts work from a user's point of view | Code, schemas, runbooks, and deploy procedures |
| Company stage, business model, and ICP | Customer names, deal terms, and anything under NDA |
| Playbooks we want repeated the same way every time | Personal data about employees or customers |

Engineering documentation lives in the `grpaiva/skilldeck` application repository, under `docs/`. This brain links to it where useful but never duplicates it.

<Warning>
  Pages here are read by AI agents that write customer-facing copy. An unmarked guess becomes a product claim. If you are not sure something is true, mark it with `status: draft` and say what is unverified.
</Warning>
